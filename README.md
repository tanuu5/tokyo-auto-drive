# 東京オートドライブ

東京の街を自動走行する3Dビュー。

**▶ デモ: https://tanuu5.github.io/tokyo-auto-drive/**

## 操作

| 操作 | キー |
|---|---|
| 時間帯（朝・夕方・夜） | 1 / 2 / 3 |
| 時間を流す | T |
| カメラ切替（車窓・追従・シネマ） | C |
| UIを隠す / 表示 | H |
| 一時停止 | Space |

## 技術

- 単一の `index.html` のみで動作（ビルド不要）
- [three.js](https://threejs.org/) r128（cdnjs CDN）
- フォント: Google Fonts

ローカルで見る場合は `index.html` をブラウザで開くか、`python3 -m http.server` などで配信してください。
